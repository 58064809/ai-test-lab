# References Index

`references/` 只放外部调研资料和成熟工具资料，不放临时任务记录。

## 分层

| 目录 | 用途 |
| --- | --- |
| `research/` | Agentic QA 调研指南、外部产品和框架研究入口 |
| `tooling/agent-frameworks/` | LangGraph、Agents SDK、CrewAI 等 Agent 框架资料 |
| `tooling/execution-agents/` | Codex、OpenHands 等工程执行 Agent 资料 |
| `tooling/mcp/` | MCP、Playwright MCP 等协议和工具接入资料 |
| `tooling/qa-automation/` | Pytest + Allure、Schemathesis、Keploy 等测试工具资料 |
| `tooling/sources.md` | 工具资料来源索引 |

## 维护规则

- 外部链接正式引用前需要重新确认。
- 不把商业宣传语直接写成项目事实。
- 调研结论应沉淀为 `docs/`、`standards/`、`skills/` 或 `templates/` 中的可执行资产。
- 临时任务文件不保留在 `references/` 中；完成后应删除。
- 非必要情况不得自研；调研应优先寻找成熟工具、官方生态和可复用工程实践。
