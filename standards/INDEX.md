# Standards Index

本文件索引 `standards/` 中的 AI 测试助手输出质量、测试设计、缺陷、风险和质量结论相关标准。

当前重点：

| 文件 | 用途 |
| --- | --- |
| `ai_output_evaluation_standard.md` | AI 输出可信度与可用性评估标准 |

维护规则：

- 标准必须服务真实测试任务，不为空泛原则堆叠。
- 新增标准前必须先阅读 `docs/architecture/agentic-qa-blueprint.md` 和 `references/research/agentic-qa-research-guide.md`。
- 非必要情况不得把标准扩展为自研治理平台。
